# Index

Master catalog of all vault contents. Tables are generated by Dataview and update automatically.

`stage` is the workflow field (see `_meta/schema.md` § Stage Values). It is not
called `status:` — that name is reserved for the Open Knowledge Format's document
lifecycle and is synthesized only at export.

---

## Sources: Unread / Unprocessed

```dataview
TABLE description, url, medium, saved
FROM "sources"
WHERE stage = "unread" OR stage = "unprocessed"
SORT saved ASC
```

## Sources: Read but Not Processed

```dataview
TABLE description, url, medium, saved
FROM "sources"
WHERE stage = "read"
SORT saved ASC
```

## All Sources (by medium)

```dataview
TABLE description, url, saved, stage
FROM "sources"
SORT medium ASC, saved DESC
```

## Atoms

```dataview
TABLE description, aliases, confidence, tags
FROM "atoms"
SORT confidence DESC, file.name ASC
```

### Orphan Atoms (no cites, no backlinks)

Inbound links are counted only from curated folders. `_meta/log.md` records
`atoms:: [[Atom A]]` on every ingest, so an unfiltered `file.inlinks` would report
zero orphans forever. Keep this in step with `_meta/lint.sh` section 4.

```dataview
LIST
FROM "atoms"
WHERE !cites AND length(filter(file.inlinks, (l) =>
    regexmatch("^(sources|atoms|topics|glossary)/.*", meta(l).path))) = 0
```

TABLE term, description, domain, stage

LIST

    regexmatch("^(sources|atoms|topics|glossary)/.*", meta(l).path))) = 0

## Provenance

### Notes with no recorded author

`generated:` is written once at creation by whichever skill produced the note.
An empty result means every note's origin is known; hand-authored notes made
straight from a Templater template legitimately appear here.

```dataview
TABLE type, created
FROM "atoms" OR "sources" OR "topics" OR "glossary"
WHERE !generated
SORT created DESC
```

### Notes never verified by a human

```dataview
TABLE type, confidence, created
FROM "atoms"
WHERE !verified
SORT confidence DESC, created ASC
```

## Maintenance Flags

### Sources older than 30 days still unread

```dataview
LIST url
FROM "sources"
WHERE stage = "unread" AND date(saved) < date(today) - dur(30 days)
SORT saved ASC
```

### Atoms with no part-of link (uncategorized)

`row["part-of"]`, not `part-of` — Dataview reads a bare hyphenated field in a
`WHERE` clause as subtraction, so the bare form silently matches nothing. Same
reasoning as the membership query in `_meta/schema.md` § Topic → Atoms.

```dataview
LIST
FROM "atoms"
WHERE !row["part-of"]
```

### Notes missing a type

`type:` is required on every curated node (`_meta/schema.md` § Node Types).
This table should always be empty; `_meta/lint.sh` fails on the same condition.

```dataview
LIST
FROM "atoms" OR "sources" OR "topics" OR "glossary"
WHERE !type
```
