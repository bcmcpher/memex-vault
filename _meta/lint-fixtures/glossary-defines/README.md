# glossary-defines

Section 6e, new in rc.3 (T2-21). The note that uses a term points at its entry
with `defines::`; compose and search read only those links. Trial 2 wrote 12
entries with no back-link and lint could not tell.

- `wired-term` — `user-atom` carries `defines:: [[wired-term]]` → silent
- `unwired-term` — nothing names it → WARN
